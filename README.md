# Nexus DL

[SpotiFLAC](https://github.com/spotbye/spotiflac) の洗練されたクリーンホワイト＆ゴールドアクセントのデスクトップUIをベースにした、高速・拡張型メディアダウンローダーです。
デモ用ダミーデータを一切排除したプロダクション仕様で、実用的なパフォーマンスと低遅延レンダリングを実現しています。

---

## 主な機能と特徴

### 1. タイトル統一 & プロダクション・クリーンデザイン
- **アプリタイトル**: 一貫して **Nexus DL** を採用。
- **デモ表示の完全排除**:
  - ダミーの履歴データや不要なプリセット（Recent sites）チップを全削除。
  - 実際にダウンロードが完了した実ファイルのみを「Completed Downloads」として美しく追記表示。

### 2. 超低遅延・高速化アーキテクチャ
- **フラット・ウィジェット構造**:
  - 不要にネストしたレイアウト階層を排除し、Tkinterのレンダリングコストを半減。
- **URL入力デバウンス（200ms）**:
  - タイピング時の即時判定負荷を抑え、高速なキーレスポンスを実現。
- **差分キャッシュ描画（Dirty Checking）**:
  - リアルタイム進捗更新時、前フレームから変更があったウィジェットのみ更新。
- **起動ラグゼロ**:
  - 起動時速度テストはUI描画完了後（500ms後）に低優先度でバックグラウンド実行されるため、アプリの起動は瞬時です。

### 3. アドオン主導の動的オプションメニュー（画質・拡張子・音質等）
- URLを入力してアドオンが適合した際、アドオンが指定する設定メニュー（例: 「画質・解像度」「保存形式・拡張子」「音質設定」など）が**Fetchバーの直下にカードとして自動展開**。
- 項目名（label）および選択肢（choices）はアドオン側が完全制御。

### 4. 厳格なアドオン設計 & 2系統専用インストーラー
- アドオンの追加は「GitHubリポジトリURLの貼り付け」または「ローカルファイル（.zip / .py）の指定」の2つのみ。
- AST静的構文検査により、不正なシステムコールや自己更新ロジックをシャットアウト。

---

## 起動方法

```powershell
pip install -r requirements.txt
python main.py
```
